# Armani Discord Bot - Privacy Policy
Last Updated: June 11th, 2026

Armani is committed to protecting the privacy of its users. This Privacy Policy explains what data is collected, how it is used, and how users can request its removal.

### 1. Data We Collect
We only collect and store data necessary for Armani's features to function. This includes:
* **User & Guild Identifiers:** Discord User IDs, Guild (Server) IDs, Channel IDs, and Role IDs. These are used to associate data with the correct accounts and servers (e.g., economy balances, warnings, levels).
* **Statistical Data:** Message counts, voice connection duration, and command usage counts. This is used solely for the leveling, leaderboards, and points systems.
* **User-Submitted Content:** Stored custom embeds, user birthdays, timezones, diary entries, and moderator notes.

### 2. Message Content & Temporary Data
* **Spam & Anti-Raid Monitoring:** Armani processes message content in real-time to detect spam, flooding, and raid patterns. This data is processed in-memory and is not stored permanently.
* **Snipe Feature:** Deleted messages and edits are stored temporarily in a volatile cache (Redis) and are completely cleared after 2 hours.

### 3. How We Use the Data
We use the collected data strictly to operate Armani's active modules within your server. We do not sell, rent, or share any user data with third-party advertisers or external developers.

### 4. Data Retention & Deletion
* **Data Retention:** Data such as warnings, level progress, and economy balances are retained until Armani is removed from the server, or until an administrator resets the database.
* **User Control & Deletion:** Users can self-manage and delete their own data using in-game commands (e.g., `,diary clear` to delete diaries). 
* **Manual Deletion Requests:** Users can request the immediate and permanent deletion of all stored data associated with their Discord account by joining our support server at https://discord.gg/heisei and contacting the development team.

### 5. Policy Updates
We may update this Privacy Policy from time to time. Continued use of Armani constitutes acceptance of any changes.
